# Headless Homelab beginnings

As a ways to break into the cybersecurity field, and to get my foot in the door
in the importances of networking & security, I opted into starting my first
homelab server.

This project will also serve to document my journey with learning linux,
self hosting, cloud servics/storage, and database handling

## Hardware
- M1 2021 Macbook pro [16gb ram, 512 ssd]
- HP Stream [4gb ram, 64 emmc flash] (temporary)
- HP pavilion x360 convertible [8gb ram, 512 ssd]
- Sansa e250 (mp3 player) [64gb]
